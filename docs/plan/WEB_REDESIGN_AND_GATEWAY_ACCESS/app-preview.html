Forebrain Harness 全站预览

菜单栏只放当前主代理（租户）的页面，全局配置只在“设置”，项目的配置在独立的“项目空间”。页面没有单独的标题层：顶栏写页面名；主代理页面、项目空间标签和设置的内容里也不再写标题：表格上方左侧是搜索、右侧是按钮，说明在表格下方；表单直接铺在标签页里。设置是全局配置，项目空间顶部是“项目 › 名称”；其余页面都属于菜单栏顶部选中的主代理。菜单栏每一项都能点击；顶部下拉可以切换主代理，下方说明随当前页面变化。示意按 1320 × 800 绘制，窄屏可横向滚动。

本轮迭代（2026-10-20）：对话里的每一种消息卡重画——卡头永远一行，长命令进正文，思考卡可折叠

  • “本轮新增”里高亮的对话 · 全部消息卡是这次的总览：一次真实的排障里，把主代理会话能出现的每一种卡片都画出来，开合与状态各给一张——思考卡、内置工具调用卡、session 类（清单 / 计划模式 / 中间笔记）、提问、权限申请、记忆类、八种 subagent_* 调用、外部 MCP 工具，以及失败 / 被拒 / 运行中三种状态。
  • 卡头永远一行：图标 + 调用摘要（与终端同一句话）+ 状态 + 折叠箭头。摘要用省略号收尾，不再换行——2 KB 的多行命令也不会把卡头撑高，状态徽标不再悬在右侧半空；悬停看完整那一行。
  • 完整调用搬进正文顶部（等宽、折行、限高 208px 滚动、可复制）：引擎认为一行放得下的（不超过 120 字符且没有换行）不重复画，短调用的卡与现在一模一样。
  • 正文就是这条调用的结果，一列，不再套第二层框：代码结果带行号，改动带 +/− 着色，搜索是标题 / 地址 / 摘要，记忆命中是“文件 · 行 + 引用行”，清单是勾选行，提问是题目 + 已选的一项，权限是原因 + 允许的范围。
  • 思考卡在主视图、子代理标签页、技能工坊是同一张：折叠成一行“思考了 N 秒”，点开才看正文，默认折叠。
  • 主代理会话与子代理会话用同一张卡（图标、摘要、状态、折叠、正文一字不差），只有列的宽度不同——宽度不够时由省略号负责，抽屉里不再另画一套。
  • 两个视图的输入框里都新增“视图 · 默认 / 简洁”下拉（同一套：审批模式旁边那一枚，子代理输入框里也有一枚）：默认画全量消息卡，简洁只留助手回答——工具调用卡与思考卡不画（新增“对话 · 简洁模式”“子代理 · 视图模式下拉”）。这是阅读方式，不是删消息：什么都没丢，等你回答的东西仍在输入框上方的面板里。
  • 八种 subagent_* 调用（run / fanout / send / status / wait / continue / close / list）沿用子代理调用卡（一句概要 + 每个任务一行），这次一并放进总览逐张核对。
  • 稿面按引擎实际下发的调用摘要绘制（ran read … · lines 15-20、failed: exit status 1、approved request permissions、asked user、saved intermediate notes …），稿面与真机是同一套话。
  • 已知要一起修的引擎文案（本稿已按修正后的样子画）：ran session_todo 与 ran exit_plan_mode 有多余空格，ran fetch … · 1 items 的单复数，以及 shell 的展示正文会把调用参数（input JSON）再打印一遍——卡头已经是那句话，正文只该给结果。
  • 抓取要审批时，对话里是这样一张卡（新增“对话 · 抓取审批”）：一句问句“要我向公开网络取这个页面吗？”、地址独占一行且长串折行不省略、右侧三档“取这个页面 / 不再询问 example.com / 不要取”（与终端同一顺序）——与终端同一组事实、同一套说法。“不再询问”自带作用范围（主机），卡片里不再另说一遍会记住什么。
  • 另外两族要审批时是同一张卡（新增“对话 · 搜索审批”“对话 · 记忆写入审批”）：问句即标题、右侧两档、第二行只放这次决定要用的那一两个事实，长串折行不省略——搜索写搜索词（加引号，它是模型自己说的话）和结果上限（工具默认 5 条、最多 10 条，与终端同一行说法），记忆写入写文件名 + 记忆作用域，其下是可滚动的笔记正文（13px 正文、长内容滚动不截断）。第二档的动词跟着这一族实际发生的事：搜索是“不要搜”（中断本轮），记忆写入是“不要记”（跳过这一条，本轮继续）。
  • 这两族没有“权限记忆”框：web_search 的决定只有“做 / 不做”，记忆写入只有“记住 / 不要记”，都没有“要不要记住这个批准”这一项；所以卡片里不解释一件不会发生的事。抓取卡的“不再询问主机”把记住的东西写在自己的按钮上，也不需要第二个框。
  • 免审批的操作不画审批卡（owner 2026-10-20）：retrieve_output 与 memories_read / search / list 在默认放行集合里（只读、且读不到记忆库以外的路径），默认根本不问，也就不会有卡；它们只有用户自己写了“询问”规则时才会被问到，那时走通用卡。

上一轮迭代（2026-10-19）：web_fetch 只剩一个参数

  • web_fetch 只剩“地址”一个参数，说明改为它现在做的事：抓取指定公开 URL 的内容，HTML 转成正文 Markdown。原来的“按要求提炼”和“处理要求”“最多下载字节”两个参数都不存在了。

更早的迭代（2026-10-17）：模型不支持图片时，消息不丢（与终端一致）；MCP 页面范围与抽屉；表格分页

  • 当前模型不支持图片时，带图消息照常留在对话里，不再退回输入框；消息下方提示“消息已保留，未发送”，没有请求发给模型。
  • 对话里还有图片时，换模型之前每条新消息都一样：保留、不发送、同样的提示。不会为了让模型能回答而丢掉图片。

  • 换到支持图片的模型后发“继续”，模型能看到原图；刷新页面或在终端续聊也一样。
  • 提示不落库：刷新后只剩消息本身，和终端一样。
  • 修正 MCP 页面范围（10-14 那版的主代理 MCP 页混进了项目级）：设置 · MCP 只增删改全局；主代理 MCP 页只看全局 + 主代理，只增删改主代理；项目空间 MCP 标签看全局 + 主代理 + 项目，只增删改项目。

  • 所有表格形式的列表下方都有分页，每页默认 10 条（owner 2026-10-18）：共 N 条、每页条数（与翻页按钮同尺寸）、上一页、页码按钮（点击跳到该页，当前页高亮，页数多时中间省略）、下一页；到头的翻页按钮置灰。
