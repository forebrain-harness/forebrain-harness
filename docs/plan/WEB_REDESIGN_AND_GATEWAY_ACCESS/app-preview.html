Forebrain Harness 全站预览

菜单栏只放当前主代理（租户）的页面，全局配置只在“设置”，项目的配置在独立的“项目空间”。页面没有单独的标题层：顶栏写页面名；主代理页面、项目空间标签和设置的内容里也不再写标题：表格上方左侧是搜索、右侧是按钮，说明在表格下方；表单直接铺在标签页里。设置是全局配置，项目空间顶部是“项目 › 名称”；其余页面都属于菜单栏顶部选中的主代理。菜单栏每一项都能点击；顶部下拉可以切换主代理，下方说明随当前页面变化。示意按 1320 × 800 绘制，窄屏可横向滚动。

本轮迭代（2026-10-17）：模型不支持图片时，消息不丢（与终端一致）；MCP 页面范围与抽屉；表格分页

  • 当前模型不支持图片时，带图消息照常留在对话里，不再退回输入框；消息下方提示“消息已保留，未发送”，没有请求发给模型。
  • 对话里还有图片时，换模型之前每条新消息都一样：保留、不发送、同样的提示。不会为了让模型能回答而丢掉图片。
  • 输入框的模型变成可点的会话模型菜单（只作用于本会话），支持图片的模型标“支持图片”；提示里的“换模型”直接打开它。
  • 换到支持图片的模型后发“继续”，模型能看到原图；刷新页面或在终端续聊也一样。
  • 提示不落库：刷新后只剩消息本身，和终端一样。
  • 修正 MCP 页面范围（10-14 那版的主代理 MCP 页混进了项目级）：设置 · MCP 只增删改全局；主代理 MCP 页只看全局 + 主代理，只增删改主代理；项目空间 MCP 标签看全局 + 主代理 + 项目，只增删改项目。
  • MCP 三处页面不再用弹窗：只能查看的行，操作栏只有“查看”，从右侧弹出抽屉，以只读表单展示全部字段，底部只有“取消”；能改的行点“编辑”、以及“添加 MCP 服务”，都从右侧抽屉打开可编辑表单，底部“取消 / 保存”。“测试连接”移到表单底部。
  • MCP 表格固定列宽、每格一行：类型只写 stdio / http（附 OAuth、请求头），状态只留徽标（失败原文、enabled: false 在悬停提示与抽屉里），来源写“全局 / 主代理 / 项目”，启用开关单独一列，去掉锁图标。
  • 所有表格形式的列表下方都有分页：共 N 条、每页条数（与翻页按钮同尺寸）、上一页、页码按钮（点击跳到该页，当前页高亮，页数多时中间省略）、下一页；到头的翻页按钮置灰。
  • MCP 列表高层在前：主代理 MCP 页先主代理、后全局；项目空间 MCP 标签依次是项目、主代理、全局。同名覆盖规则不变。
  • 记忆列表去掉排序下拉框，改为表头排序（参照开源组件库的表格）：“创建时间”“更新时间”列头带上下箭头，当前排序列与方向高亮；点未排序的列按新→旧，再点切换；默认更新时间新→旧，换排序回到第 1 页。时间列不再折行。
  • 表格操作栏统一为同尺寸的图标按钮：查看（眼睛，技能页原“详情”）、编辑（铅笔）、下载、删除（红色）、允许 / 拒绝、上移、停止；缺某个动作的行留占位，图标上下对齐。所有图标按钮鼠标悬停（或键盘聚焦）时在上方显示文字提示。
  • 技能表格的来源列写“主代理”，不再带主代理名（与 MCP 表格一致；当前主代理已在菜单栏顶部）。
  • 技能工坊顶栏去掉面包屑左侧的返回箭头，点面包屑“技能”返回。
  • 项目空间的面包屑（项目 › 名称、目录、信任状态）移到顶栏，取代原来的“项目空间”标题，与技能工坊一致；顶栏下面直接是标签页。
  • 项目空间各标签去掉标题：原标题右侧的按钮移到表格上方的工具栏（搜索、筛选之后，靠右），说明文字移到表格下方，与其他提示合成一行。主代理级页面不变。每个标签的表格上方左侧都有搜索框（规则指令、权限、通道补上）。
  • 菜单栏里主代理的页面（项目、规则指令、技能、MCP、子代理、模型服务、工具、权限、记忆）照同样的要求改：去掉标题，按钮移到表格上方右侧，左侧是搜索框（子代理、模型服务、权限补上），说明移到表格下方。
  • 顶栏不再显示模型名（对话页、技能工坊）；当前模型只在输入框的模型选择器里。顶栏的项目标签只写项目名（去掉“项目 ·”），悬停提示“进入项目空间”。对话抽屉标题只写“对话”，不带“主代理 main”；MCP 添加抽屉标题、判定验证的命中位置也只写“主代理”。
  • 顶栏的会话标题最长 360px（窄屏时更短），超出截断加省略号，悬停显示全文；标题右侧的项目标签、心跳、工作台和右侧按钮都不缩小、不被挤出；项目空间、技能工坊面包屑里的名称同样处理。
  • 登录 web 端后首页就是新对话页（设计稿打开即是这一页）；新对话页顶栏不再显示“未命名对话”，也不显示“工作台”按钮，发出第一条消息后才出现；发出第一条消息后顶栏标题就是这条消息的第一行（最多 50 字，与引擎的会话命名规则一致）。
  • 新聊天（还没有消息）时，问候语、输入框和快捷入口一起在对话区垂直居中（技能工坊的空白新建同样）；发出第一条消息后输入框在底部。
  • 菜单栏深浅色切换按钮从菜单栏底部移到顶栏最右侧（“中文”右边），悬停提示显示在按钮下方；菜单栏的折叠 / 展开按钮从顶部 logo 旁移到它原来的位置（底部“设置”右侧，折叠后在“设置”下面）。
  • 设置也照此改：MCP、钩子、共享技能三个表格去掉标题，搜索在左、按钮在右，说明在表格下方（钩子补上搜索框）；外观、审批默认、记忆三个表单不套框、不加标题，单选都改成标准单选组（主题色带色块，审批模式竖排带说明），审批默认与记忆的“保存”在表单底部；配置文件把路径和按钮放在编辑器上方；运行状态合成一张列表。
  • 项目空间的“概览”标签改名“项目设置”，表单直接铺在标签页里（不套框、不加表单标题）：去掉统计卡片（各标签里都看得到数量）和“危险操作”卡片，“删除项目”移到“保存”右侧。
  • 项目空间的会话标签改成表格：标题（点开即进入会话）、模型、消息数、心跳（每 N 分钟 / 已暂停）、创建时间、更新时间；两个时间列头排序，默认更新时间新→旧；下方分页。操作栏只有图标按钮“打开”。
  • 提示条改紧凑：单行约 20px 高，上下不留白。
  • 主代理工具页改成表格：工具、说明、分类、类型（只读 / 有副作用），可搜索、按分类与类型筛选，下方分页。操作栏只有一个图标按钮“查看入参”，在该行下方展开入参表（参数、类型、必填、说明），再点即“收起”。
  • 项目页改成表格：项目、路径、说明、对话数、更新时间；“项目”“更新时间”列头排序（去掉排序下拉框），置顶的始终在最上面；下方分页。名称可直接点进项目空间；操作栏为图标按钮：进入项目空间、置顶 / 取消置顶、删除。
  • 项目空间的定时任务、通道改成表格，下方分页。定时任务：名称、计划、投递至、下次执行、已执行次数、启用（即原来的暂停 / 恢复）；操作栏为立即执行、执行记录、删除。通道：通道、投递标识、配置（密钥只显示末 4 位）、启用；操作栏只有编辑，在弹窗里填该通道的配置项，去掉了页面级“保存”；没配置的通道不能启用。
  • 项目指令（原在规则指令标签）、记忆作用域（共享 / 仅本项目，原在记忆标签）移到项目设置标签，和其他项目设置一起用底部“保存”；两个标签只剩各自的列表。记忆作用域改为表单里常见的单选组（参照开源组件库：圆形单选 + 文字，横排），放在项目指令下面，说明随选项变化。

上一轮迭代（2026-10-14）：MCP 三层作用域与全字段弹窗

  • 菜单栏新增「MCP」页：列出全局与本主代理的 MCP（不含项目级），与技能页同一套界面（标题行 + 搜索行 + 表格）。多出「来源」一列（全局 / 主代理），主代理的行可启停、编辑、删除，全局行只读并直接跳到能改的地方。
  • 三层，各页只增删改自己那一层：设置 · MCP 只看、只改全局；菜单栏 MCP 看全局 + 主代理，只改主代理；项目空间 · MCP 看全局 + 主代理 + 项目，只改项目（需信任 + 逐条同意）。不同名叠加，同名整条覆盖，不做字段级混合。
  • 设置 · MCP 与项目 · MCP 改为同一套列表 + 弹窗；被主代理覆盖的全局条目在它自己那一层标「未运行 · 被主代理 main 覆盖」。
  • 弹窗编辑整条：名称、类型、命令或地址、必需、启用、连接超时（秒）、请求超时（秒），高级里按类型给请求头 / 环境变量 / OAuth / SSE / SHA256 校验 / 默认审批模式；密钥值预填 [REDACTED]。
  • 底栏「测试连接」用当前表单值试连（不写配置、不关弹窗），结果显示已连接的工具数与耗时，连不上就显示服务端原文；保存中禁用、400/409 原文显示在弹窗里。
  • 新状态词：已连接 · N 个工具 / 已允许 · N 个工具 / 待确认 / 已禁用（界面，下个会话起）/ 配置里已禁用（enabled: false）/ 连接失败。

更早的迭代（2026-10-11）：每个对话都属于一个项目

  • 新聊天页参考 ZCode：问候语 + 居中输入框，左上角项目胶囊；必须选了项目或文件夹才能发送，新文件夹自动建项目。
  • 文件夹选择改为系统原生式对话框：后退 / 前进 / 上一层、位置侧栏、单击选中、双击进入。
  • 输入框：“＋”菜单（附件、目标、技能），单独的 Agent / 计划模式切换，模型右侧加推理强度，上下文圆环。
  • 用户消息悬停“回到这里”：恢复代码、对话或两者，可撤销。
  • 输入框上方的诊断面板移进工作台（概览 / 上下文 / 工作目录 / 变更文件）；工具调用只在消息窗口里流式显示。
  • MCP 启动失败放在对话开头；新增“另一端运行中”“目录已不存在”提示。
  • 定时任务、通道移进项目空间（菜单栏去掉这两项）；技能工坊改为从技能页进入（新建技能、详情、发现并安装），可返回；安装改为弹窗；去掉项目归档，删除项目会连同对话；新建项目、新建定时任务、记忆查看/编辑改为弹窗。
