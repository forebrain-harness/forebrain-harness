登录页预览

浏览器第一次打开 gateway 时看到的页面：输入一次 gateway token，换取会话 Cookie，之后不再询问。整页白底、纯色，主题色跟随“设置 → 外观”。可以切换下面的状态、主题色和语言查看各种情况；左边是桌面宽度，右边是手机宽度。

状态
主题色
语言
127.0.0.1:6060/login?redirect=%2F1200 px
127.0.0.1:6060/login?redirect=%2F390 px

这一页的行为

  • 任何页面在未登录时都会被带到这里，登录成功后回到原来要去的页面（地址里的 redirect）。
  • token 输入框是密码框、不自动填充；错误时直接显示服务端返回的原文 invalid gateway token，不加额外解释，也不用浅红底。
  • 点开终端里打印的登录链接（/login#token=…）会自动提交，并立刻从地址栏抹掉 token。
  • 页脚显示当前连接的 gateway 地址和版本，同一台机器开了两个 gateway 时能分清登的是哪一个。
  • 右上角可以切换语言；登录页不显示菜单栏，也不发出任何业务请求。
