子代理先中断，再停止

终端的子代理视图里，Ctrl+C 已经只作用于这个子代理：按一次打断当前这一步、等你发话，再按一次才停止它，主代理都不受影响。网页的子代理标签照同一规则改：停止按钮拆成先“中断”、再“停止”两段。

真实尺寸，可以点：中断、输入后发送、或中断后再点停止。

规则

  • 按钮：运行中是“中断”（两竖线，灰色）；中断后同一位置换成“停止”（红色方块，即现在的停止按钮）。不再一下就停掉。
  • 等你发话：对话里加一行“已中断 · 等你发话”，和收尾的“已工作”线同一样式；状态行“工作中”隐藏；计时不停，因为这次派发还没结束。
  • 恢复：你的消息一送达，图标、卡片、状态行都回到运行中。别的会话发来的消息也会让它继续，和主对话被打断后收到消息一致。
  • 文案：现有但没用上的状态词“等待输入”改为“等你发话”，标签、菜单、卡片三处一致。
  • 不变：Esc 的含义、停止后的收尾样式、跑批会话只读（不显示输入框与按钮）。
