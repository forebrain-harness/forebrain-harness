本轮迭代

  • 别的代理（另一个终端或网页会话）发来的消息，左对齐、不套框，用对方的身份色竖线引出。
  • 每个代理一枚方形身份块：两个字符取名字最后一段，颜色由名字固定；子代理是父代理同色的空心块。圆形节点只属于本会话自己的步骤。
  • 回合进行中收到的消息，成为活动线上的一个节点；自己发出的消息有了结果，汇总成「投递状态」。
  • 权限模式不同的来信先等你放行。放行后它落进对话，再由它开始新的一轮。
  • 抽屉顶部是这个目录正在改的文件，以及谁在改；我和别人同时在改的文件会标出来。
  • 这个目录还有别的代理时，git stash 这类命令要你批准，卡片里写明会影响谁。
