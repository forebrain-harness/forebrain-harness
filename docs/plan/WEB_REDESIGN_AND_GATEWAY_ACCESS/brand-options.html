三套方案共同遵守的规则

  • 纯色：全站禁止渐变、毛玻璃（backdrop-blur）和半透明叠色，只用实色；阴影只保留给浮层（下拉、弹窗）一档。
  • 白底：内容区、对话窗口、工作台一律 #FFFFFF；卡片用 1px 细线分隔而不是底色。
  • 深浅只在菜单栏：切换按钮移到菜单栏底部，只改菜单栏；代码块始终用浅色的 monokailight。
  • 字体：界面与正文统一为系统无衬线（苹方 / 微软雅黑 / Segoe UI），等宽字体只用于代码与路径，替换现在的衬线体。
  • 三栏：删除原来独立的会话栏，“新聊天”、搜索和会话列表并入菜单栏；心跳从工作台移出，入口放在菜单栏底部；工作台的“运行中的代理”为空时不显示。
