web 端同缺陷原型 · 基线 dev 329790da · 2026-11-20 · 视觉沿用 peer-coordination-preview.html 与已实现的 PeerMessageCard.vue（plan 200 §3）。待 owner 确认。

改什么

  • 子代理视图收到 peer 来信（主代理插话、同目录会话来信、同伴子代理来信），从「右对齐用户气泡 + 原样 <agent-message>/<cross-session-message> 信封」改为活动线上的一张来信卡：发送方身份块作节点，名字 + 类别 + 同目录 + 时间，正文由发送方色竖线引出。
  • 这张卡与主视图同一个组件 PeerMessageCard.vue，不新造样式；实时与回放一致。
  • 用户亲手发的插话仍是右对齐用户气泡；旧事件（payload 无 origin）仍按用户气泡回放，向后兼容。

为什么这样画

来信不是读者自己说的话，不套用户气泡；发送方色竖线让两个代理的来信不会读成一段对话。引擎送达事件已带 origin（TUI 修复 ac09eb14 / 329790da 已落 dev），web 只需按 origin 把 subagent_input_delivered 路由到来信卡，而非用户块。

「现状对照」页签是当前缺陷的样子，供对比；其余页签是改后。新增按产品样式画，说明都在本栏。
