模型配置入库

plans/259–268 原型第四版，2026-11-07。可直接操作：左栏进「对话」或「设置」，设置里切「模型 / 记忆 / 变量」；表格上添加、编辑、删除都真生效。样式沿用「配置入库后的设置页」原型，数据为示例。

本次新增：对话页的思考强度选择器（2026-11-12）

  • 对话页输入框里，模型选择器右侧多一个思考强度选择器。
  • 选中一个模型时，思考强度默认选中「设置 · 模型」里给它配的值。
  • 会话最后设置和使用的模型与思考强度一并落库；打开之前聊过的会话（网页或终端），回显库里记录的这两项。
  • 之后在设置里改这个模型的思考强度，已有会话不变；再次选中该模型时取新值。
  • 可选档位与设置里该模型「思考强度」下拉相同，配的那一档后面标「模型设置」。
  • 左栏点「对话」开会话抽屉：三条示例会话各存了不同的模型与思考强度，点开即回显。抽屉沿用现有实现，这里只画「新聊天」和会话行。
  • 请你确认：① 设置里配了具体档位时，对话页不列「默认」（设置里是「默认」才列出并选中）；② 模型打开「允许关闭思考」时，对话页多一项「关闭思考」；③ 模型关了「思考模式」或没有可选档位时，不显示这个选择器；④ 配的那一档标「模型设置」；⑤ 新会话沿用现有规则：取主代理最近使用的模型，思考强度跟它一并取，不取设置值。

此前新增：主代理可用它派子代理（plans/283，2026-11-10）

  • 每个模型一个开关「主代理可用它派子代理」，默认关；升级时已有模型一律关。打开的模型，在表格里服务商那一行末尾标「子代理可用」。
  • 开关在「添加模型 / 编辑模型」抽屉里（订阅来的行也能改）；订阅登录第 3 步每个勾选的模型后面多一个「子代理可用」复选，默认不勾。
  • 只管主代理派子代理时自己挑模型。你亲自选的不受限：计划审批里的「交给其他模型执行」与评审、子代理页给某类子代理指定的模型。
  • 请你确认：① 开关放在主区（模型名称下方）而不是高级配置里；② 表格在服务商那一行末尾写「子代理可用」，而不是新增一列；③ 订阅第 3 步用第二个复选。

怎么用

  • 设置 · 模型：点「添加模型」开右侧抽屉；点表格里的编辑图标得到「编辑模型」并带出该行；点删除是确认弹窗（默认模型会被拒）。
  • 抽屉里：选服务商 → 接入点自动填地址与协议；「接口协议」是下拉（输入框只显示协议名称，选项两行）；高级配置可展开。
  • 「订阅登录」三步：选订阅 → 登录 → 勾选模型并添加进表。点订阅来的行编辑，看到只读的来源卡片。
  • 对话页的模型下拉与思考强度下拉、设置 · 记忆的两个下拉都能点开并切换；会话抽屉里能切换会话、开新聊天，输入框能发送。

已定的规则（都体现在这版里）

  • 全局一张表，放设置页；同一服务商与模型可配多条，四项相同只能一条，重复保存会指到已有那条。
  • API Key 只显示末四位；订阅行的 Key 与地址只读。
  • 开关类用开关（思考模式、允许关闭思考）；同类多选用复选（支持的输入：图片 / PDF / 视频 / 音频），标题与复选框同一行、不换行。
  • 「自定义协议」只在服务商为「自定义」时是「接口协议」的第四项：地址即完整请求地址，不拼接任何路径。
  • 思考强度档位由官方接口或官方文档确定；确定不了才让勾选。标签：关闭思考 / 极低 / 低 / 中 / 高 / 最高 / 极致。
  • 界面文案把模型自带的能力一律称作「默认值」，不出现内部数据文件名。
