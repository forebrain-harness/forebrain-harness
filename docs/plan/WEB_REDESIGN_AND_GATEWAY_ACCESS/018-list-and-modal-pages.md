## 步骤

每个页面都是同一个模式：
- `PageTopRow`：标题 + 一句说明 + 右侧按钮，"刷新"在最右；
- 下面一个表格或列表，用 `.tb-wrap` / `.list.boxed`；
- 新建、编辑都在弹窗里；
- 删除用 `ConfirmDialog`；
- 文案照原型逐字。

### 步骤 1：规则指令（主代理与项目）

- **列表**：表头为文件、作用、更新时间、操作。行操作只有"编辑"。下方一行小字"<位置>；保存后新会话生效。"
- **"新建规则文件"按钮 → 弹窗**：
  - 主代理：下拉只列支持且尚未创建的文件，提示"只列出会被读取、且还没创建的文件。"；
  - 项目：类型、目录两个下拉。
  - "创建"后直接打开编辑弹窗。
- **编辑弹窗**：`size="xl"`，标题为文件名，内容是 019 的编辑器，下方"保存后新会话生效。"。
- **项目空间的规则指令标签**两段，各用一个 `.flat` 段：
  - "项目指令 · 注入本项目每个会话的开头，新会话生效。· 保存"加文本框；
  - "规则文件 · 项目目录里的规则文件，新会话生效。· 新建规则文件"加表格。
- `RulesFileEditor.vue` 被弹窗取代，删除。

### 步骤 2：模型服务

- **列表**：
  - 表头为顺序（主用 / 回退 N 徽标）、服务商、模型、Base URL、API Key（已保存后四位或"未设置"）、操作；
  - 行操作：上移（非首行）、编辑、删除。
  - 标题行按钮："添加模型服务"（主按钮）、"刷新"。
- **添加 / 编辑弹窗**：
  - 服务商下拉，Base URL；
  - 模型标签输入，复用 `components/providers/ModelChipsInput.vue`，下面列"该服务商的模型"快速加入；
  - API Key：已保存时显示"已保存 ••••xxxx"和"更换"；否则为密码框，"输入或粘贴 API Key"；
  - 提示"API Key 保存到 ~/.forebrain/.env，配置文件里只写引用。"。
- **保存语义**：弹窗"保存"即把整份列表 PUT 回去（计划 014 的接口是整表往返）。去掉页面级的"保存"按钮。上移、删除同样立即保存，删除前用 `ConfirmDialog`。

### 步骤 3：权限（主代理与项目）

- **列表**：表头为动作（允许 / 询问 / 拒绝徽标）、工具、规则内容、操作（编辑、删除）。
- **标题行按钮**：
  - 主代理："判定验证"、"添加规则"（主按钮）；
  - 项目："规则匹配测试"、"添加规则"。
- 表格下方写存储位置的路径，小号等宽字。主代理页最下方再加一行"默认审批模式在'设置 → 审批默认'；项目规则在各项目空间；单个会话可在输入框旁临时切换。"
- **添加 / 编辑弹窗**：
  - 动作、工具两个下拉，只有"规则内容"需要输入；
  - 提示写入位置：项目为"写入 .forebrain/safety.json，项目已信任时生效。"，主代理为"保存在主代理工作区。"。
- **判定验证弹窗**：
  - 工具下拉加输入框，"验证"按钮；
  - 结果在弹窗里显示：判定、命中规则、命中位置；
  - 按钮为"关闭""验证"。

### 步骤 4：MCP（全局与项目）、钩子

- **MCP 列表**：
  - 表头为名称、命令或地址、类型、状态、操作；
  - 全局的操作：编辑、启用 / 禁用；
  - 项目的操作：编辑、删除；待确认的服务为"允许""拒绝"；
  - 标题行："全局 MCP 服务 · 对所有主代理生效，新会话起作用。· 添加 MCP 服务"（项目版文案见原型）；
  - 下方写配置文件路径。
- **MCP 弹窗**：
  - 名称、类型（stdio / http）、命令或地址；
  - "必需"开关（"连接失败时会话不启动"）；
  - 写入位置的提示。
- **钩子**：
  - 列表表头为事件、匹配、命令、操作（编辑、删除）；
  - 标题行"钩子 · 对所有主代理生效。· 新增钩子"；
  - 弹窗字段：事件下拉、匹配下拉（"匹配全部工具"或具体工具）、命令。

### 步骤 5：设置的其余标签

- **审批默认**：`.flat` 段，"默认审批模式 · 对所有主代理的新会话生效；单个会话可在输入框旁临时切换。· 保存"，下面三档单选卡与配置路径。
- **记忆功能**：`.flat` 段，三个开关的 `.list.boxed`，"保存"在标题行。
- **配置文件**：`.flat` 段，"forebrain.yaml · 保存前按运行时的规则校验……· 保存并生效 · 刷新"，下面是路径和 019 的代码编辑器（YAML）。
- **外观、运行状态**：保持分组卡片，外观只调间距使其与原型一致。

### 步骤 6：项目

- **列表**：
  - 标题行："项目 · 每个项目有独立的项目空间……· 新建项目 · 刷新"；
  - 搜索框加排序下拉；
  - 每行：名称（置顶、目录不存在徽标）、说明、路径与更新时间；操作为进入项目空间、置顶 / 取消置顶、删除。
- **新建项目弹窗**（`projFormModal()`）：
  - "目录"输入框加"浏览…"，打开 `plans/029` 的 `FolderDialog`；
  - "项目名"默认取目录名；
  - 目录已是项目时，显示"已是项目 X。打开它"并禁用"创建"，用 `plans/025` 的 409 `project_root_taken`；
  - 否则提示"目录必须已存在，不能在 ~/.forebrain 内。"。
- **删除项目弹窗**（`delModal()`）：
  - 标题"删除项目「X」？"；
  - "将同时删除 N 个对话和 M 个定时任务，无法恢复。"，数据来自 `delete-preview`；
  - 显示目录；"目录里的文件不会删除。"；
  - 有对话在运行时显示提示、不显示输入框；
  - 否则要求输入项目名确认，用 `ConfirmDialog` 的 `typedConfirm`；
  - 按钮"删除项目和对话"为危险色。

### 步骤 7：记忆与项目空间其他标签

- **记忆**：
  - `.flat` 段，标题行"记忆 · 本主代理的通用记忆文件（不属于任何项目）……"；
  - 搜索、排序、"删除所选""重置全部"一行；
  - 表格；分页；
  - "查看 / 编辑"打开弹窗（`memEditModal()`）：标题为文件名，右侧"更新于…"；内容是 019 的编辑器；底部左侧"删除此文件"（核心文件为"清空内容"），右侧"取消""保存"。
- **项目空间**：
  - 会话：`.flat` 段"项目会话 · 在项目根目录运行。· 新建项目会话"加 `.list.boxed`；
  - 记忆：两段，"记忆作用域"单选卡与"项目记忆"列表；
  - 权限、MCP：同步骤 3、4；
  - 概览：保持分组卡片，照原型。
