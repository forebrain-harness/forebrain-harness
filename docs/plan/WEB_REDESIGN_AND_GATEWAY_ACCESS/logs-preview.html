plans/284–288 原型第一版，2026-11-11。位置：设置 · 高级 · 日志。全部可操作：选时间、点级别、选来源/项目/会话/类型、搜索、在直方图上拖一段、翻页、点任意一行开抽屉；左栏「对话」里的报错卡片可直达日志。数据为示例，样式沿用已有原型。

怎么解决「多个会话的输出混在一起」

  • 每条记录都带来源、进程、项目、会话、轮次、代理；选了会话就只剩它的记录。
  • 一次模型调用是表里的一行，点开才是它自己的请求与响应，别的会话进不来。
  • 调用抽屉的「同一时刻的其他调用」把并发的调用按会话各画一道，点哪道开哪次。
  • 失败、断流、没跑完的调用保留完整请求体；成功的只留头尾各 32KB，并写明省略了多少。

可以试的路径

  • 左栏「对话」→ 报错卡片上的「查看日志」：带着会话与时间范围跳过来，报错那行闪一下。
  • 点那行 400 的模型调用 → 「请求」看到完整请求体，「响应」是上游原话。
  • 点一行 200 的调用 → 「响应」是拼好的思考、正文、工具调用，「原文」是逐条 SSE。
  • 直方图上拖一段 = 把时间范围缩到那一段；抽屉开着时按 ↑ ↓ 换行，Esc 关闭。

请你确认

  1. 默认只勾「信息 / 警告 / 错误」，「调试」要手动点开。
  2. 网关的接口访问记录归到类型「接口访问」；成功的 GET 记为调试级，默认不出现。
  3. 鼠标移到某行，会话列末尾出现筛选图标，点它只看这个会话；抽屉里另有「只看这一轮」「前后 1 分钟」。
  4. 抽屉宽 720，模型调用四个标签：概览 / 请求 / 响应 / 原文。
  5. 不做自动刷新，只有刷新按钮（与「不做实时推送」一致）。
