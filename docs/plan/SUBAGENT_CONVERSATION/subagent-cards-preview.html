subagent_* 工具卡片：终端与网页预览

计划 012–016 的确认稿。左边是 TUI 的样子（文字与计划 013 第二、三节逐字相同），右边是网页的样子（计划 014）。后面还有 plan-reviewer 视图（计划 015）和网页的退出计划模式审批（计划 016）。两边由同一份数据画出，点任务行会进入该 subagent 的视图。运行中的任务名后面的计时每秒走一次；结束的任务（成功、失败、取消）后面是最终耗时。

一种卡片八个 subagent_* 工具与 plan-reviewer 这类没有派发调用的执行，全都用 fanout 那种卡片：一行头部，下面每个任务一行。
不再出现原始 JSON、原始 task id、派发 prompt、status=ok、"subagent … spawned / ended" 文字行、· 66 tool uses 统计行。
每个任务都有自己的时钟运行中：任务名后面是走动的计时；结束（成功、失败、取消）：最终耗时；没开始过的（等待、跳过）不写。只有一个任务的卡片，头部不再重复写时长。
plan-reviewer 也是同一套头部请另一个模型评审计划时，卡片与其它 subagent_* 卡片一样写 Starting / Running / Ran / Failed to start，不加主语；不再是主语错误的 "subagent plan-reviewer spawned plan-reviewer"。
查询类是快照status、wait、close、list 显示调用那一刻的状态，不随后续事件变化。
终端颜色：头部 214（橙），✓ 绿、✗ / × 红、! 黄，正文与 assistant 正文同亮度（不再半亮）。网页只用现有的 --forebrain-* 纯色变量，不用渐变。类型名（general-purpose 等）和最近工具的标签不翻译，与终端相同。
