计划 391 的视觉定稿稿。结构严格对齐 Claude Code 2.1.332（三个 webview 与三个 provider：forebrain.chatSidebar / forebrain.chatSecondary / forebrain.sessionsList），视觉按 forebrain web 主题全新设计：frontend/src/assets/main.css 的平面白、发丝线、墨色与品牌三 scheme。Dark 只在 webview 跟随 VS Code 主题（宿主 activeColorTheme 触发 html.dark），web 整站本期仍亮色。三 scheme 改的是**全应用的强调色族**：内容区强调（按钮、衬线、选中态、链接、上下文环）与活动栏和侧栏标一起换，与 main.css 那句 “switching recolours everything in unison” 一致。零网络：所有交互都是页内模拟，没有真实数据库、网关调用或密钥。

结构照厂商，不照旧表面

      
三个 webview 与三个 provider：会话在 secondarySidebar（when: !forebrain.doesNotSupportSecondarySidebar），旧版 VS Code 回退到活动栏容器；Sessions 是独立容器的独立 webview。旧的 iframe 嵌整站在 Step 10 拆掉。

    

    

      
token 不进 webview

      
webview 只发白名单 RPC，宿主带着 Bearer 转发。面板里没有 login#token=，也没有可读的凭据；断线由宿主重连并回放快照。

    

    

      
同一套主题，两种明暗

      
webview 直接引入 main.css，暗色只加一段 html.dark；宿主把 activeColorTheme.kind 推下来，webview 加/撤类名。web 整站不设 dark 类。三 scheme 由同一族 token 驱动，内容区与侧栏一起换，不做局部染色。

    

    

      
信任走 VS Code

      
面板内不画 TrustDialog。扩展声明 untrustedWorkspaces supported: false；选目录时按三分支：落在受信任工作区内自动写记录、之外走宿主原生模态、工作区未信任则受限不发。
