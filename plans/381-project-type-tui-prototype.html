会话出生时冻结自己的类型。已经说过话的会话（或执行过 /new、/model、/rename 的会话——这些命令会立刻建会话行）保留出生类型，回复里给出 /new；只有还没建行的启动会话跟随新类型（后台把它重新绑定到新类型的运行时），不需要 /new。面板始终点名屏幕上的会话属于哪一种。
改类型先问一句
与 Web 一致：选了别的类型先到确认页，复述「从什么改成什么」与生效范围，光标默认停在 No。选当前类型、按 Esc 都不写入，对话里不留回复。
跑批的两个方向都写清后果
改成后台跑批：任务在网页创建，终端只能查看；回复不建议 /new（跑批会话在终端里发不了消息，首条消息会被拒绝）。改出后台跑批：任务页与任务通知不再显示，已建任务仍可查看；在只读查看器里改出时，回复提示重启终端才能开始新类型的会话。
