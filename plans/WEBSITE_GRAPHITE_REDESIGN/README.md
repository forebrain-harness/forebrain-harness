## Findings considered and rejected

- **换 logo / 重绘 mark.svg**: not in scope — the owner has uncommitted edits
  in `docs/public/mark.svg`; the redesign is theme-only and must not touch it.
- **Mermaid 主题从 neutral 换色**: rejected — `neutral` is already gray-scale
  and fits graphite; `theme/index.js` stays untouched.
- **移除暗色模式（内容区恒白的产品规则字面执行）**: rejected — graphite
  defines its own dark rail palette (#141416 family), so dark mode maps onto
  the system instead of being deleted.
- **给文档站加品牌切换器（navy/teal/graphite）**: rejected — the product's
  docs surface is graphite-only by decision; a switcher is scope creep.
- **zh 内容 parity（原裁决：不做，内容战役另行立项）**: **OVERRIDDEN by the
  owner 2026-10-08** — 中英文内容必须完全一致，1比1翻译 is now a hard
  campaign constraint, implemented as Plan 003.
- **Internals 页面删除（memory-internals 等"讲原理"页）**: rejected — the
  owner's ruling is that main paths lead with value, not that principle
  pages must die; they are demoted to the "Internals" group, last in the
  sidebar, untouched in body (Plan 002).
