三、本稿决策（frontend 未定义处的延伸）
  1. 侧栏/目录 = rail：文档站的导航面按产品 rail 语义取色（光面 rail-light，暗面 rail-dark），激活项左侧 2px 墨条用品牌墨。
  2. 保留暗色模式：graphite 本身定义了暗 rail 面（#141416 族），暗色文档页是它的自然延伸；暗面品牌按钮沿用 rail-dark 的反白签名。
  3. 暗色提示块：状态色取同一色阶的上一档（success #47CD89 / warning #FDB022 / danger #F04438，frontend rail-dark 已用 #F04438），底统一压到 rail hover 面 #1E1E21。
  4. danger 软底 #FEF3F2：frontend 只定义了 warning/success 的 soft 面；#B42318 与 #FEF3F2 同属一个色阶，取其 50 步。
  5. 链接加下划线：品牌墨近黑，不加下划线无法与正文区分；下划线用发丝 strong 色，悬停转实。
  6. Mermaid 保持 neutral 主题：本身即为灰阶，契合石墨，不改。

Forebrain Harness
The terminal AI work agent that also runs as an agent gateway

An open-source agent product for developers and everyday productivity users who want terminal work, service-backed gateway APIs, multi-channel integrations, memory, skills, subagents, and execution controls in one runtime.

Get Started Architecture GitHub

Terminal-First Coding Agent

Forebrain Harness's interactive TUI is built for local development work: live sessions, slash commands, approvals, visible tool progress, session resume, local workspace access, and shell-oriented execution.

Gateway Runtime, Not A Sidecar

The same runtime is exposed through the Forebrain Harness gateway with HTTP APIs, WebSocket chat, run events, sessions, files, permissions, skills, memory, and channel delivery.

Multi-Channel Agent Gateway

Adapters for Telegram, Discord, Slack, WhatsApp, WeCom, Weixin, Feishu, DingTalk, QQ, Signal, Matrix, Mattermost, email, SMS, webhooks, and more.

Office Productivity Agent

The gateway and channel surfaces can support daily productivity workflows such as document-heavy tasks, knowledge recall, recurring automation, approvals, and team communication.

Stateful Work Beyond Chat

Sessions, runs, context budgets, compaction, Active Memory, transcript continuity, durable memory, and subagents give durable structure for long-running work.

Safety As A Product Surface

Permissions, approvals, sandboxing, guardrails, path controls, and audit surfaces are separated so powerful agents stay observable and controllable.

Getting Started

This is the first guide page for Forebrain Harness. It explains what Forebrain Harness provides, what to expect during the first run, and where to go next after the interactive session opens.

Install

Install with npm (Node.js 18+; macOS arm64/x64, Linux x64/arm64, Windows x64):

⧉
# one global install, then verify
npm install -g @forebrain-harness/forebrain
forebrain --version
bash

Or with Go (Go 1.26+ and a C compiler): see Build and Release for the full toolchain. The fts5 tag enables full-text memory search.

CGO_ENABLED=1 go install -tags fts5 github.com/forebrain-harness/forebrain-harness/cmd/forebrain@latest
bash

What You Need

  • a local terminal session
  • a Forebrain Harness installation
  • valid model-provider credentials for the main agent
  • a workspace you are willing to trust for file access and tool execution
TIP

Run forebrain --version before the first session; the build embeds the web UI and needs CGO on every platform.

WARNING

Prebuilt archives attach to each GitHub release; a source build downloads CJK tokenization dictionaries on first use.

DANGER

Only trust workspaces you control. The permission and sandbox layers in Sandbox and Permissions assume a trusted root.
