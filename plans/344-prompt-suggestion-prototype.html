INTENT

01 / PREDICT, DON'T PRESCRIBE

预测用户会输入什么

提示词要求模型预测用户自然输入的下一句（"我正要打这个"），而非助手认为该做的事。评价语、问句、助手口吻、多句一律过滤为沉默。净化、加权词数与拒绝链逐条移植 CC 的 q / C / D。

02 / GHOST, NOT ACTION

幽灵文本只填草稿

Tab / → / End 把推荐填入草稿，光标落到末尾，用户确认后才发送。打字立即消散且不再恢复；新回合开始即清除。空框 Enter 直发推荐（已裁决，对齐 Claude Code，acceptMethod=enter）；按键提示行不显示（已裁决）。

03 / ONE ENGINE, TWO SURFACES

引擎共享，两端同义

生成、过滤、状态机、退避都在 pkg/turn；幽灵显示与按键采纳由各端实现同一契约。推荐是 push-only 事件，不落库、不回放。连续 20 次未采纳→安装级全局 streak 达 20→静默降频至 1/10（无任何提示）；采纳一次或重新开启开关即清零恢复每回合。开关已入 web 设置页与 TUI /config。
